# QPrint

QPrint is a college printing and Xerox management web application built with Next.js.

## Getting Started

### Prerequisites

- Node.js and npm
- A configured database
- Required environment variables in a local `.env` file

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file in the project root and configure the required database and application settings.

**Do not commit `.env` or expose private credentials in GitHub.**

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Technology Stack

- Next.js
- TypeScript
- Prisma ORM
- Database configured through environment variables

## Deployment

QPrint is intended for deployment on [Vercel](https://vercel.com/).

Import this repository into Vercel and configure the required environment variables and database connection before deploying.

## Development

Edit the application source files and run the development server to test your changes locally.
